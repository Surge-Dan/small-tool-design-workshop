# 三个可运行的交互案例

按本地路线规划、组合状态管理、像素编辑三个方向展示复杂交互。下载单个HTML，在浏览器打开即可；素材、CSS与JavaScript都已内嵌，无需构建、账号或网络。GitHub文件页面展示源码，不是在线运行页面。

| [darkroom.html](darkroom.html?raw=1) | 上传PNG／JPEG／WebP／AVIF、曝光、双色映射、确定性颗粒、裁切焦点／放大、边框／日期、原图对照、撤销重做、长边1800px PNG导出 | 本地像素处理，无生成式修复；编辑不跨刷新保存；最大25MB／3200万像素，解码仍受设备内存限制 |

## 图像与真实UI

纸雕地图、透明服装素材板、海边建筑示例照片由内置imagegen制作。示例照片不是用户上传照片或真实外拍记录；服装不是实际商品。三款的文字、控件与状态都由代码实现，不能把生成素材当整页界面。

HTML已保留可复用的图像data URL。衣橱的`art()`按素材实际边界做SVG裁切；不要改成平均四等分而露出相邻衣物。暗房预览与导出复用`renderTo()`，不能用CSS滤镜只改显示、不改输出像素。素材商业使用权仍须按具体用途核实，不声明已取得第三方商品／人物授权。

## 实际检查

2026-10-18使用Edge无头浏览器、新上下文、禁用网络、file URL首次打开；三款均检查320／390／1280宽度，未发现横向溢出与页面脚本错误。README中的图片是390×844实际初始画面，不是交互测试本身。

核心操作检查包括：地图加入／删除／撤销、出发时间联动、锁定位置保持、超时提示；衣橱换搭／撤销、锁定保持、保存后差异对比、跨刷新恢复；暗房色调改变像素、撤销恢复、方形裁切、真实PNG下载、上传成功与解码失败保留原图。另检查了两款记录工具损坏存储的数组回退。

未进行手机真机、Safari、微信内置浏览器、屏幕阅读器、长期压力测试或平台审核；原型不是生产上线承诺。浏览器不允许本地存储时，漫游与衣橱会提示无法保存。离线状态不等于无设备兼容限制。
