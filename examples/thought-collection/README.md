# 念头寄存处

彩色折片收藏盒：把暂时不想解决的话收好，之后由自己补充、拆开和重新表述。离线移动端单 HTML 原型，无账号、上传、模型调用或运行时外部依赖。

直接用浏览器打开 [index.html](index.html)。初次为空收藏；点击「看看五条示例」查看设计，示例及其编辑不会写入私人记录。推荐使用新版 Edge / Chrome。

## 已实现

- 自选五色折片；先放着、安排应用内回看或拆开想想。
- 搜索原文与历史记录；归档、最近删除、恢复；菜单移动不依赖拖动。
- 用户填写关联理由，可解除；拆分 1–8 条，提交前由用户确认，保留来源。
- 追加补充和新表述，原文不覆盖；选择两次记录比较。
- 最近 20 次会话操作可撤销；永久删除需确认并清空撤销历史。
- 私人卡片默认无文字，主动引用或重写后导出 1200×1600 PNG；不自动携带历史、关联或日期。
- 写入失败时保留当前输入；示例与私人草稿隔离；多窗口写入使用 Web Locks 串行化，过期窗口拒绝覆盖并提供载入最新。

## 交给下一位开发者

必须保留「收藏浅槽 → 有文字的折片 → 展开内容」的层级。颜色由用户选择，不编码情绪或潜意识；折片与关系由明确操作决定。正文必须保持 DOM 文本，不能用整屏图片加热点替代。圆润控件、文字留白、折边和纸材质服务于整理行为，不新增宣传口号或固定底栏。

当前纸张、阴影、浅槽、折边由 CSS / 内嵌 SVG 实现，无需生成图片。若未来增加精细纸纹，可先生成不含文字的轻量材质，再嵌入本地资源；不要让素材承载动态文字和按钮。

- `screen.html`：界面与交互源文件。
- `core.js`：数据模型与校验；版本只追加、拆分原子提交、删除恢复规则。
- `fidelity.css`：视觉细节。
- `build.py`：合成为独立 `index.html`，并记录 SHA256。
- `home-browser.png` / `detail-browser.png`：真实浏览器渲染，不是概念生图。
- `browser-check.json`：实际检查范围，不能等同真机验收。

## 数据边界

记录存于本浏览器 `localStorage`，不加密、不跨设备同步、不构成备份。清理浏览器、更换浏览器或移动 HTML 路径可能导致原记录无法访问。请勿作为重要或敏感记录的唯一副本。

未提交草稿和撤销历史只在本次页面会话中保留。临时模式关闭后丢失；不支持 Web Locks 的浏览器仅允许临时编辑，不伪装成已持久保存。多窗口保护限同源、遵守本应用写入协议的窗口，不能防止外部程序直接改存储。

回看日期只供应用内筛选和查看，不承诺关闭页面后推送。不做心理诊断、评分或建议。PNG 是下载，不保证手机浏览器直接写入系统相册。

