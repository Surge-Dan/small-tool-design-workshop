# AI 风格反模式与设计拒绝规则

这份规则用于设计前自检和明显模板化时的重做。它不是禁止所有留白、圆角或渐变；用户明确要求时，用户意图优先。重点是拒绝无语义的组合。

## 直接拒绝的组合

- 顶部无意义英文小字 → 左上角标题 → 带标点的空泛中文口号；
- 蓝紫渐变、玻璃卡片、霓虹光晕、漂浮粒子作为默认气氛；
- 随机英文、编号、坐标、伪状态标签和装饰性 Logo；
- 大面积空白配一句“高级感”文案；
- 标题、按钮、三张卡片、图标和大圆角的无差别堆叠；
- 主题只体现在背景色，换成别的主题页面依然完全成立。

## 四个快速判断

### 1. 文字删减测试

删掉每段文案后，用户是否仍然知道下一步？不能删的文字留下，不能改变操作的句子删掉或改成具体说明。

### 2. 组件职责测试

每个按钮、标签、装饰和动画都要回答“它帮助用户完成什么”。回答不出来就移除。

### 3. 换题测试

把主题名称和颜色替换成另一个完全不同的主题：若结构、文案、材质和结果仍然成立，说明设计没有从内容出发。

### 4. 真实产品测试

不看视觉稿，只看页面文字和操作，用户能否完成任务？如果不能，先修任务路径，不要继续加视觉。

## 重做顺序

1. 删除无意义英文、口号和伪标签；
2. 合并重复的引导页和说明文字；
3. 把卡片改成能表达内容关系的列表、页、表单或结果区；
4. 只保留一个主题化视觉签名；
5. 重新检查按钮、状态和结果解释。

## 具体 case 的校准

“选择心情并生成一张卡片”是低风险、低复杂度的轻记录任务。默认不需要封面、欢迎语、仪式化转场或三段式引导。更好的首屏是日期、标题、选择、可选记录和生成按钮组成的一页笔记本。
