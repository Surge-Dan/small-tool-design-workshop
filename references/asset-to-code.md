# 从设计图到可还原的开发

有插画、摄影、复杂材质、角色、图像小样转代码，或需要开发交接时读取。目的不是交更多文件，而是避免下一位AI只看一张截图，靠猜测把效果做丢。

## 先拆代码层和素材层

| 内容 | 优先实现 | 不应替代为 |
| --- | --- | --- |
| 中文、数字、输入、按钮、列表、布局 | 真实DOM／CSS；图形工具可用可编辑文本层 | 整页图片、错误字形、透明热区 |
| 简单线条、刻度、几何图标、轻投影 | CSS／内联SVG，统一参数 | 不必要的生图或大背景 |
| 精细插画、水彩、角色、摄影、复杂物件 | 已有授权图片，或制作时生成独立素材 | emoji、粗糙SVG、只写“请做高级一点” |
| 纹理、剪纸、立体静态物件 | 局部纹理／透明物件素材＋代码层 | 用整页截图当背景承载所有UI |
| 必须随操作实时变化的图形 | 可用的SVG／Canvas／WebGL方案 | 静态图冒充实时处理；无需要强行3D |

如果主视觉决定效果，先做一个代表性素材，放进最终手机尺度验证，再扩展同家族；代码并不总能替代资产制作。仅用排版已足够时直接代码，不为丰富交付强行生图。共享阴影要避免素材自带投影后CSS重复加阴影。

## 最小素材配方

每个需要交接的关键素材，按实际需要留下：

- **标识／用途**：如A01衣物；在哪一页、什么状态、占多大显示区域。
- **当前状态**：已提供、已内嵌、待生成、待授权；写真实文件／HTML定位方式，不把计划说成已有资产。
- **规格**：比例、建议像素尺寸、透明／实色背景、主体视角和安全边距；位图通常按显示尺寸约2倍起步，再按清晰度与体积调整。
- **视觉锚点**：轮廓／笔触、色彩职责、光向／材质、裁切；引用本次认可样本，不仅写风格编号。
- **制作方法**：复用／授权获取／生成／代码绘制；生成时有可直接使用的提示词与实际可共享参考。
- **交付方式**：HTML已内嵌的资源位置、允许分享的原文件或仍需用户补充；来源、许可／署名及不确定项。

只有一个素材时几行就够，多项用简表。不要默认新建复杂资产数据库。没有资产需求就不交空清单。

示例配方（示例，不是本Skill已提供的素材）：

> A01 衣物插画｜待生成｜列表类别图，显示约96×80 CSS px。建议输出透明PNG约384×320，主体四周留安全边距。正面略俯视的折叠上衣，统一深蓝轮廓、明亮蓝白色块、少量柔和阴影；无文字、无按钮、无背景面板。若已有认可图，作为画风与视角参考。最终按实际文件尺寸裁切，不能把小图拉伸替代。

提示词需要包括主体、视角、构图与边距、色板、笔触／材质、光源、背景与排除项。主体替换时保持画风锚点，但轮廓与姿态要可辨。透明需求须在工具参数中实际启用（工具支持时），不能只写“透明底”就当获得alpha通道。生成后实际查看边缘、裁切与一致性。

## 交付深度随请求变化

- **只要设计图**：图＋简短还原建议，明确静态概念、哪些要先制作素材、哪些要用真实UI。不给不存在的原文件或假运行截图。
- **单HTML原型**：实际素材按离线约束内嵌；说明图像在哪、如何保留和替换，不强迫用户维护多文件。来源和许可仍保留。
- **开发参考包**：继续使用现有JSON和打包器。已用素材填`visual.assets`，把配方及内嵌定位写入该项`usage`；`source`写可共享来源，不放本机绝对路径／密钥。待生成素材不是已用资产，详细配方写入`limitations`，并把相关需求标为planned／partial。这样信息会进入自动生成的HANDOFF，而非只留在聊天里。

已有打包器复制HTML和规定的证据附件，不会按`visual.assets.source`自动收集原始素材；不要将资产塞进`evidence`冒充测试。离线原型从内嵌图片提取可供后续复用，许可允许时说明提取位置；用户确需独立源素材时另行交付实际文件并核对清单，不声称它们已经在自动ZIP里。参考图若不能分享，用可公开的观察说明，不写一个接手者打不开的本机路径。

需要重生成的资产先说原因，能复用就不重新调用。截图里的原图细节无法无损提取时说明局限，不许诺像素级复原。生成素材不能自动认定有商业授权，第三方标志、人物和隐私另核实。

## 给下一位AI的短指令

按本次交付替换括号内容，不原样留下占位词：

> 按提供的原型及设计记录实现，不套通用页面。保留[已确认的构图、中文层级、控件和关键资产特征]。文字、数值、输入和按钮用真实UI；复用[实际提供／已内嵌素材与定位]。[待生成素材]先按所附配方制作并检查，再嵌入代码，不用emoji或粗糙占位替代。不把整页图片加热区当实现。先按相同内容、状态和视口还原关键画面，再扩展状态；保留业务规则、错误恢复及离线要求。未实现／未授权部分按清单处理，不当成已完成。

面向用户可以只说：“这套插画建议先让AI生成透明底素材，再嵌入代码；按钮、文字和清单仍由代码实现。提示词和尺寸我已附上。”只有确实附了配方才这样说；无生图能力时交可执行配方并注明尚未生成，不声称已经完成视觉还原。
