# 画面对照与显示检查

需要同尺度查看参考/关键状态，或检查手机显示时读取。工具仅依赖Python标准库和浏览器执行能力，不安装渲染库，不生成页面模板或审美分数。

## 整理已有画面

在原型项目目录建立短清单，使用已取得授权且实际查看过的本地位图。不要为了对照下载受限远程媒体，也不将用户参考提交到Skill仓库。

```json
{
  "title": "结果页对照",
  "items": [
    {"role": "reference", "label": "布局参考", "path": "reference.png", "source": "用户提供"},
    {"role": "current", "label": "当前结果", "path": "result.png", "state": "result", "viewport_width": 390}
  ]
}
```

```text
python scripts/design_review.py --manifest <项目目录>/review.json --output <新文件>/review.html --html <项目目录>/prototype.html
```

输出离线总览，图片按记录的CSS视口宽度展示；未记录宽度时标为未知，不宣称等尺度。支持PNG/JPEG/WebP，每张最多16MB、最多20张；不会覆盖文件。`reference`是参考，`approved`是已认可画面，`current`是操作者声明的当前截图，不自动证明来源。

current项可携带原有`prototype_sha256`，提供`--html`时核对；不一致会拒绝，缺绑定标为未核验。只使用实际截图时的绑定，不为通过校验重标旧图。该总览不自动成为证据，也不打包未知许可参考图片。

## 读取实际边界

先用可用浏览器打开实际原型、设置视口和状态，再读取`scripts/viewport_probe.js`并用该浏览器的页面执行能力调用：

```text
(文件中的函数)({container: ".app", maxWidth: 390})
```

将`.app`替换为真正约束整个原型的容器，不只选择一张窄卡片。独立检查390×844、320px和宽屏；不同状态复用同一检查。脚本只读DOM，返回容器宽度/居中、页面横向溢出、越过容器的元素及固定元素候选。主动横向画布、裁切和运动中位移可能被列出，需要人工判断；空issues也不证明控件位置合理。

固定控件若在容器外，例如底栏用了`width:100vw`，即使主容器宽度正确也要修复。浏览器视口变化不证明软键盘、系统分享或真机行为。

字体字段只表示声明及加载状态，不能证明具体中文字形采用了目标字体；实际看字形，必要时用浏览器字体检查能力。该脚本不验证离线、动画、导出或好看，相关检查仍实际执行。没有浏览器工具时不伪造探测结果。
