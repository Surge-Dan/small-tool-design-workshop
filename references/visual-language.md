# 视觉语言：让界面像它所服务的内容

只在需要定视觉方向、排版或高保真原型时读取。

视觉执行顺序和对抗式验收由 [visual-sop.md](visual-sop.md) 负责；这里提供具体视觉推导。简约、复杂、复古、科技或插画均可高保真，不把某一种美学当通用默认。

缺少已确认的布局/视觉简报、也未获直接执行授权时，先提出具体方向并确认。产品功能清楚不等于已确认视觉；用户的明确参考和局部修改要求优先。

## 视觉选择顺序

1. 先确定场景、使用频率、核心对象和操作成本；
2. 按内容与动作关系选择布局，再提炼物件、材质或其他视觉语义；
3. 选择具体字形、配色、素材和运动语言，按真实内容精修。

不要从“高级、治愈、科技、简约”开始。它们没有足够的设计约束。

尊重用户给定的风格和参考，从具体内容决定信息层级、组件形态和结果表达。熟悉的交互控件可以复用，主题辨识度不必靠每次发明新的布局；也不能把所有主题统一成纸张手册。信息密集、编辑器和游戏应有各自适合的结构。

## 版式优先级

- 首屏先放用户要理解或操作的内容；
- 标题承担命名，不承担空泛宣言；
- 辅助文字只解释规则、状态或下一步；
- 空间感来自真实的留白和对齐，不来自大块空白加一句口号；
- 组件按内容关系分组，不按“卡片看起来漂亮”分组。

## 笔记本/手册类界面

把纸张当成信息结构：

- 日期、页边、横线、装订线、批注可以表达页面身份和记录关系；
- 标题、选项、记录区、行动按钮应像同一页里的不同书写层级；
- 选择项适合使用行、方框、短标签，不要自动变成五张圆角卡片；
- 结果卡应像从页面中自然长出来的另一页，而不是突然切换成通用渐变卡。

这是笔记本主题的参考，不是所有轻量工具的默认皮肤。纹理、印章、贴纸和插画可以服务情绪、品牌和辨识度，但不能压过内容、削弱对比或挡住操作；只有没有依据或干扰体验时才删除。

## 色彩和字体

- 颜色优先表达状态、主题或层级；
- 强调色数量按画面关系决定：克制界面可用单色，拼贴或多色场景可用多色，但主次和状态角色要清楚；
- 中文标题可用有性格的宋体/明朝体，正文使用清晰的系统黑体；
- 不为“设计感”强行加入英文、数字编号或伪栏目名；
- 字号、行高和对比度优先保证移动端阅读。

展示级原型按内容选择有辨识度且清晰的字体；可以采用许可允许的外部字体，但离线版本须内嵌所需字形并提供回退。图标保持同一家族或一致的线条、尺寸和光学重量，插画保持统一的形状、色板、描边和材质。资源选择按需参考 [visual-resources.md](visual-resources.md)。

## 实际画面精修

从真实内容检查以下关系，不机械套用统一字级、8px网格、固定圆角或字体黑名单：

- **字形与数字**：中文、英文、数字及标点的字重与基线协调；连续变化的数字按需用等宽数字；金额、次数与单位分层但光学对齐。检查真实字体与回退字体，不只看CSS名称。
- **构图与密度**：明确第一视觉焦点、次要信息和操作的空间关系；高频任务把当前操作抬高。密集内容用分组与节奏建立秩序，留白组织阅读与情绪，不靠空白撑版面。
- **色彩与状态**：品牌色与成功、警告、错误、禁用各有职责；状态同时有文字或形状反馈。装饰允许多色，但内容对比与主次不能消失。
- **组件与光学重量**：图标虽同为24px也可能显得一大一小，按实际画面微调；描边、边缘、圆角、按压态与触控边界协调。
- **素材与材质**：在最终显示尺寸检查主体裁切、清晰度、透明边缘、光源、遮挡与投影；不能让精细摄影与粗糙装饰互相削弱。
- **真实状态**：短标题与长标题、密集列表、大数值、空白与错误、完成与返回共用同一语言；不要只打磨最空的首屏。

需要参考时少量选取与本次目标有关的画面，拆解层级、字形、构图、素材与运动关系，并说明如何转化为本工具；不复刻整页，也不虚构参考来源。原创方向同样应有具体判断。

首次渲染后选择最影响质量的少量问题，局部打磨并对照前后状态。达到已确认方向与验收即可停止，不循环改色、不为了展示能力重做流程。

## 动效

结构阶段就确定需要保持的对象关系，再落实反馈与运动节奏。按任务采用翻页、揭示、布局衔接或状态反馈，不强制数量；方向明确的表现性运动也可主动设计。动效的规格、中断、焦点和减少动效按 [motion-and-interaction.md](motion-and-interaction.md) 执行，不能只写“自然流畅”。

## 移动端底线

仅在目标为移动端时以390×844为主要基准，关注320～414宽度；主要操作可触达、可见、可读，不依赖悬停，键盘焦点可见。桌面或其他明确目标按确认尺寸和输入方式设计，不强行缩成手机。移动端详细模式见 `mobile-h5-patterns.md`。

有浏览器工具时检查实际渲染的首屏层级、长内容、选中/错误状态、结果与导出图；发现裁切、拥挤或不一致时修正。缺少工具时明确视觉仅做静态检查，不凭 CSS 推断已通过显示验收。

以确认的视觉方向为验收依据，检查字级、行距、对齐、留白节奏、插画清晰度及边缘、材质/光影的一致性，以及动效是否自然。素材加载失败、字体替换或渲染降级时核心内容仍应可读可操作，并如实说明与目标效果的差距。
